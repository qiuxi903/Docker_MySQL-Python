# SQL · Py 课堂实验室（Docker_MySQL-Python）

一个 Docker 一键部署的课堂教学网站：学生打开浏览器就能写 MySQL、跑 Python，什么都不用装。
每个学生一个互相隔离的独立数据库，注册账号或游客一键进入，手机、平板、机房电脑都能用。

本项目由 AI Coding 编写，基于 [MIT](LICENSE) 协议开源。

详细文档（项目结构、功能细则、API、使用指南、部署与运维手册）见 [PROJECT.md](PROJECT.md)。

## 项目特点

- **打开就能用**：新账号自动送三张经典教学表（EMP 员工 / DEPT 部门 / SALGRADE 工资等级）。
  **编辑器和答题区一律空白**，不预填任何示例命令，写什么由学生自己决定；想建自己的表，点「新建数据表」填表名和字段即可。
- **像真的 mysql 命令行**：SQL 不用写分号，多条语句一行一条；输出是 mysql 风格的深色控制台，
  语句、结果集、影响行数、耗时逐条追加，结果表格带行号和斑马纹。
- **像真的 IDE**：CodeMirror 编辑器（行号、语法高亮、括号匹配、自动缩进、补全），
  Python 支持多文件、跨文件 `import`、每敲一个字自动保存，`input()` 交互也能用。
  沙箱是纯命令行环境，不支持 tkinter / PyQt / pygame 等图形界面（页面有提示），用 `print` 输出结果。
- **练习自动判分**：练习页分三层——**清单**（一套题一张卡片，显示题数、总分、我的得分、通过进度）→
  **试卷详情**（题目、分值、状态，不含答案）→ **做题工作台**（与主页布局一致，进入即显示题干）。
  提交后显示本题得分和本套累计得分；写了一半的答案切题、返回、刷新都不会丢。
- **内置 Navicat 图形界面**：课堂题目大多是 Navicat 式操作，所以 SQL 题默认用**仿 Navicat 界面**作答——
  连接树、对象列表、数据网格、设计表、查询页、**可视化查询构造器（拖拽字段连线做多表连接）**、视图、函数 / 存储过程、触发器、导入导出向导，
  鼠标点完就能交卷；系统把图形操作翻译成 SQL，判分口径和手写 SQL 完全一致。也可以一键切回纯 SQL 模式。
  面板内文字不可选中，右键是自建菜单（打开 / 设计 / 新建 / 删除 / 复制 / 运行 / 美化等），触屏长按等同右键；
  手机竖屏下连接树变成左侧抽屉，工具栏图标化，弹窗铺满屏幕。
- **整卷导入**：老师已有试卷不用逐题抄。把题干、参考答案、数据库导出放进一个文件夹，
  压缩成**一个 zip** 上传，自动拆题、配对答案、识别题型、剔除数据库里已有的答案产物，一次发布整套题。
- **题库（素材包）**：MySQL 库 + Python 文件的组合，学生一键导入到自己名下随便改随便跑，不判分；
  整库还能生成私有分享链接发给指定同学。
- **用户系统与管理后台**：个人中心（统计、自助改密、退出所有设备）；
  管理员有总览、用户与游客管理、批量操作、新建账号、操作日志。
- **严格隔离**：每个账号一个独立数据库 + 只授权本库的专用 MySQL 账号；
  Python 代码在独立沙箱容器执行，限 CPU、内存、进程数和时长。
- **手机电脑都好用**：手机竖屏底部标签栏（个人中心 / 管理 / 退出收在「我的」里）+ 抽屉，电脑横屏左右分栏；
  MiSans 字体、GitHub Primer 配色、深浅色主题、页面与卡片动效。

## 技术栈

| 层 | 技术 |
|---|---|
| 后端 | Python 3.12 + FastAPI + Uvicorn（`.env` 一行可切 3.14） |
| 数据库 | MySQL 5.7（官方镜像，数据持久化到 Docker 卷） |
| 驱动 / 解析 | PyMySQL、openpyxl |
| 前端 | 原生 HTML/CSS/JS + Vue 3 + CodeMirror 5（全部本地内置，无 CDN、无构建步骤） |
| 字体 | MiSans（本地内置 4 个字重） |
| 部署 | Docker Compose：`web`（API + 静态页面）/ `runner`（Python 沙箱）/ `db`（MySQL） |
| 测试 | 111 项本地单测 + 228 项端到端烟测 |

## 快速开始

```bash
git clone https://github.com/qiuxi903/Docker_MySQL-Python.git
cd Docker_MySQL-Python
cp .env.example .env          # Linux/Mac；Windows 直接复制一份改名 .env
# 编辑 .env，改掉 MYSQL_ROOT_PASSWORD / ADMIN_PASSWORD / RUNNER_TOKEN 三个默认值
docker compose up -d --build
```

等 MySQL 初始化 20~40 秒（`docker compose logs -f web` 出现 `Application startup complete` 即就绪），
浏览器打开 **http://localhost:8000**。

第一次使用：

1. 点「游客试用」直接进入，或注册账号（字母开头、仅字母数字 3-20 位；密码至少 8 位且同时含字母和数字）。
2. 在 MySQL 工作台的编辑器里输入 `SELECT * FROM emp`，点「运行」，看到 emp 表 14 行结果。
3. 切到 Python 页，在 `main.py` 里写 `print("hello")`，点「运行」，在下方控制台看到输出。
4. 切到「练习」做题，或到「题库」导入老师发的素材包。

更多用法（导入自己的数据、Python 连库、交作业、出题）见 [PROJECT.md](PROJECT.md) 的使用指南。

## 三种账号

| 角色 | 怎么来 | 能做什么 | 数据保留 |
|---|---|---|---|
| 管理员 | `.env` 里的 `ADMIN_USER / ADMIN_PASSWORD`（默认 admin / admin123，**上线务必修改**） | 全部功能 + 用户管理 + 给其他账号开通出题权限 | 长期 |
| 注册学生 | 自助注册 | 写 SQL、跑 Python、做题、导入题库；管理员开通后可以出题 | 长期，换设备不丢 |
| 游客 | 登录页一键进入 | 浏览 / 导入题库、做练习题；不能出题或发布 | 3 天内自动续用，数据 7 天不用自动回收 |

每个账号对应一个独立数据库（游客是随机的 `g_xxxx`，注册用户是 `u_账号名`），
数据库账号只授权自己的库，互相看不到、改不了。

## 界面与功能

### MySQL 工作台

- 左侧数据库树：切换数据库、点表名预览数据和结构、新建数据库 / 数据表、导入文件、导出 `.sql`、分享链接、存为素材包草稿。
- 中间编辑器：无需分号，一次可以写多条语句；`Ctrl+Enter` 运行。
- 下方控制台：逐条回显 SQL、结果集、影响行数、报错原文和耗时，超过 500 行只显示前 500 行。

### Python 编辑器

- 多文件标签栏，最多 30 个 `.py`；新建、上传、删除、跨文件 `import`。
- 每次输入自动保存；上传的文件是临时的，刷新或退出登录自动删除。
- 预置 `query()` / `query_dicts()` / `execute()` / `get_conn()`，直接操作自己的数据库，也可以手写 `import pymysql`。
- 交互式 `input()`：控制台出现输入框，提示语即时可见；超时自动结束。

### 练习

**清单 → 试卷详情 → 做题** 三层：

- 清单按 **MySQL / Python / 客观题 / 错题本** 分类，一套题一张卡片。
- 卡片显示题数、总分、我的得分、已通过题数和进度条；做完的卡片标「已完成」。
- 试卷详情列出题目、分值、状态，**不显示标准答案**；点题目进入做题。
- 做题页进入即显示题干，初始化数据点「题目数据」才展开；左侧是本套题目和 SQL 题的沙箱数据库。
- 提交后显示通过与否、本题得分、本套累计得分，以及你的结果与正确答案对照。
- 答题草稿按「账号 + 题号」保存在浏览器，切题、返回试卷、刷新页面都会恢复。

判分方式覆盖：SQL 结果集一致、顺序敏感、只比数据、只比单值、结果包含、改数据状态、整库状态；
Python 输出一致、包含、正则、多组测试用例；单选、判断、多选、填空。

### 题库（素材包）

- 一个素材包 = MySQL 部分（一个数据库）+ Python 部分（若干文件），导入后不判分，适合让学生自己练。
- 广场里可以预览表结构和数据、Python 文件内容，一键导入到自己名下。
- 老师可以给自己出的题打包，也可以只把整库分享给某个同学（私有链接）。

### 管理后台

- 总览：注册用户、游客、今日活跃、有出题权限、已禁用、数据库总数、练习题、判分提交、近 7 天注册。
- 用户 / 游客：搜索、按权限筛选、分页、详情、开通出题、重置密码、禁用 / 解禁、强制下线、删除、批量操作、新建账号。
- 操作日志：登录成功 / 失败、注册、改密和管理员操作。

## 老师出题

### 方式一：逐题出（出题工作台）

练习页点「出题」→ 选题型 → 填题目、初始数据、标准答案 → 右侧实时试跑 → 保存并发布。
可指定「所属试卷」和「本题分值」；同一张试卷的题会归到练习页的同一张卡片上。

- SQL 题的初始数据支持手写 SQL、上传 `.sql` / `.csv` / `.xlsx`，或直接选一个已有数据库导出。
- 支持 6 种题型和十余种判分方式，标准答案只留在服务端，学生拿不到。

### 方式二：整卷导入（推荐）

1. 把一份试卷的材料放进同一个文件夹：
   - 题干：`.txt` / `.md`（含 `1、2、3…` 编号的小题）
   - 参考答案：`.txt` / `.md`（按 `-- 1` / `---8` 分隔）
   - 数据：`.sql` / `.myd`（Navicat、mysqldump 导出都行），也可以是 `.csv`
2. 整个文件夹压缩成 **一个 `.zip`**（Windows 右键「发送到 → 压缩文件夹」即可）。
3. 练习页 →「出题」→「导入题目包 批量」→ 拖入 zip。
4. 核对解析结果（题目、题型、判分方式、数据表、自动剔除的答案产物、质量提醒），点「创建 N 道题」。

导入时会自动处理：GBK / UTF-8 编码、Windows 中文文件名、题号配对、题型识别、
数据库快照里已经包含的答案产物（建的表、插入的行、视图、触发器、存储过程）、
`DELIMITER` 包装的触发器和存储过程。重复导入只跳过本套内已有的同名题。

出题权限默认关闭，管理员在「管理 → 注册用户」里按人开通。

## 部署方法

| 场景 | 做法 |
|---|---|
| **宝塔面板（推荐，域名 + HTTPS）** | 宝塔装 Docker，上传项目，配置 `.env`，`docker compose up -d --build`，域名反代 `127.0.0.1:8000`，申请 SSL，`.env` 里设 `TRUST_PROXY=1`。 |
| **内网机房 / 本机** | 教师机装 Docker Desktop，`docker compose up -d --build`，学生访问 `http://教师机IP:8000`。 |

国内服务器拉不动 docker.io 镜像时，在 `.env` 里取消注释 `PYTHON_IMAGE` / `MYSQL_IMAGE` 两行（daocloud 源）再 build。
完整步骤（HTTPS、备份、升级）见 [PROJECT.md](PROJECT.md) 的部署手册。

## 数据与安全

- 密码 PBKDF2-SHA256 加盐 20 万轮，不存明文；登录态用随机 token，注册用户 30 天滑动过期，游客 3 天固定过期。
- 每账号独立数据库 + 独立 MySQL 账号，只授权本库；MySQL 不对外暴露端口。
- Python 在独立 runner 容器执行：无外网、只读根文件系统、CPU 8 秒、内存 256MB、进程数 64、总时长 300 秒。
- 学生拿不到 SQL 标准答案和 Python 期望输出，判分后才返回对照。
- 管理员可随时禁用账号、强制下线、重置密码；改密会踢掉其他设备。
